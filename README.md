# Multi-Brand Pneumatic Gripper Sizing Tool

  A browser-based engineering tool for selecting and validating pneumatic grippers across major
  industrial brands.

  ## What it does

  Input your workpiece parameters and finger length — the tool applies brand-specific force derating
  curves and outputs:

  - Safe / Unsafe verdict with live force graph
  - Correct pneumatic port fitting size
  - Purge port specification
  - Sensor mounting guidance

  Brands covered: **Schunk, SMC, Festo, Zimmer**, and others.

  ## Why it exists

  Incorrect gripper selection and wrong fitting specification are a recurring source of commissioning
  failures in industrial automation. This tool eliminates that error at the design stage, before
  anything reaches the shop floor.

  Built and deployed across the engineering team at Effica Automation, Coimbatore.

  ## How to use

  No installation. No dependencies. Open the HTML file in any browser — or use the live version:

  **[Launch Tool](https://kumarmechatronics.github.io/Yashwanth-Kumar/)**
